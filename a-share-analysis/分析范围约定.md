# 分析范围与风格约定（默认）

自 **2026-11-11 晚** 起，日更与空仓布局默认遵守以下范围与风格。历史归档不回溯修改。

## 风格：进取，不要安全保守

用户要的是**偏进攻的看法和仓位**，不要再给高现金、等阴线、领涨日一律 0%、连续确认过长的保守方案。

硬数据纪律不变（只用交易所/资金/拥挤/财报/商品，不用媒体观点）。变的是把同一组数据翻译成仓位时，优先跟趋势、跟主力、跟连涨确认，而不是优先避险。

落地：

| 旧默认（停用） | 新默认 |
|---|---|
| 现金底线 50%，执行仓常年 24%–26% | 空仓权益执行 **65%–85%**，现金 **15%–35%**；没有极端破位时不要把现金放到 50% 以上 |
| 领涨日（单日 >3%）一律不开仓 | 连涨第 2 日可开确认仓，第 3 日且主力继续流入可加到主线仓；领涨只限制**第一天追高打满**，不否决已连涨方向 |
| 电子成交分位 ≥85% 完全禁止加码 | 拥挤主线仍可配 **通信设备 / CPO / PCB 主题联接**，单方向上限 **12%–18%**；不要用拥挤分位把执行仓锁在 0% |
| 成长/券商必须成交连续 ≥2 日 ≥1.60 万亿且证券流入 | 单日成交 ≥1.50 万亿且板块主力净流入、价格连涨，即可加；不必等三盏灯全亮 |
| 阴线才加、间隔 1 日、流出上限卡死 | 主线以趋势加仓为主；阴线是加仓窗口不是唯一窗口 |
| 先写否决再写配置 | **先给进攻结论和执行仓**，风险用仓位上限和清仓线控制，不要用「维持 0%」代替看法 |

清仓线仍要写清楚（例如跌破本轮回流起点或主力连续两日大流出），这是进攻仓的风控，不是改回保守。

## 默认不分析、不配仓

除非用户当次明确点名，否则不要：

- 展开基本面 / 估值 / 拥挤 / 资金 / 左/右侧建议
- 写进空仓执行表或加减仓规则
- 用它们当大盘或风格的主结论

名单：

| 方向 | 口径 |
|---|---|
| 银行 | 申万银行、中证银行、银行 ETF/联接 |
| 电力 | 申万公用事业中的电力、电力 ETF/联接 |
| 沪深300 | 指数及跟踪该指数的 ETF/联接 |
| 中证500 | 指数及跟踪该指数的 ETF/联接 |
| 煤炭 | 申万煤炭、煤炭 ETF/联接 |

大盘环境仍用上证、深成、创业板、科创50、两市成交额、涨跌家数、两融。不要为了交代风格再写一段银行/电力/300/500/煤炭点评。申万全表若必须引用，这五个只可出现在原始涨跌数字里，不展开、不加仓。

## 默认仍分析

通信、电子（含 CPO/PCB/光模块/通信设备）、计算机/软件、化工、医药、券商/非银、电力设备/电池、食品饮料/白酒、传媒、机械/机器人、科创50/半导体，以及用户当次点名的其他方向。

空仓方案不要再预留银行、电力、沪深300、中证500、煤炭的执行仓。现金比例按其余方向重算。

## 何时重新分析

用户写出上述名字，或说「看一下银行/电力/300/500/煤炭」时，仅对该次、仅对点名的方向恢复完整分析。
