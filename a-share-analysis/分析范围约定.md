# 分析范围与风格约定（默认）

自 **2026-11-11 晚** 起，日更与空仓布局默认遵守以下范围与风格。历史归档不回溯修改。

## 风格：进取，但仓位必须由历史硬数据算出来

用户要偏进攻的看法，**不要**高现金、一律 0%、为了安全而空着。  
同时 **不要** 再发明一套机械执行规则（例如「连涨第 2 天开确认仓、第 3 天主力还在进就加主线」「成交 ≥1.50 万亿就可加」「领涨日一律如何」）。这类日期/阈值 SOP 停用。

仓位怎么定：

1. 先描述当前盘面（涨跌、成交、主力、拥挤分位、估值、业绩、商品）。
2. 在**可核对的历史样本**里找同类状态：同一板块或同一指数，过去出现过「类似连涨天数、类似拥挤/成交分位、类似放量或缩量、类似回吐后再回流」时，后面 3 / 5 / 10 / 20 个交易日的涨跌分布、胜率、中位数、最大回撤。样本来源和筛选条件要写明；样本太少就标明，不得用规则补洞。
3. **用这组历史结果决定方向和仓位**：历史续涨占优就给主线大仓（进取体现为把胜率偏多的方向给足，而不是把现金留很高）；历史明显均值回归或回撤很大，就减仓或换到历史表现更好的方向，这是数据结论，不是改回保守。
4. 拥挤分位、领涨、阴线只是样本的标签，用来对齐历史，**单独一条不构成开仓或禁仓**。
5. 先写进攻结论和执行仓，依据是上面的历史统计，不是「第几天」。清仓线也尽量来自样本里亏损交易的共同特征（例如跌破回流起点），不要另写一套死规则。

禁止再把下列句子当默认操作：连涨第 N 天、三盏灯全亮、阴线才加、间隔 1 日、成交必须 ≥X 万亿、拥挤 ≥Y% 锁 0%。

## 默认不分析、不配仓

除非用户当次明确点名，否则不要：

- 展开基本面 / 估值 / 拥挤 / 资金 / 左/右侧建议
- 写进空仓执行表或加减仓规则
- 用它们当大盘或风格的主结论

名单：

| 方向 | 口径 |
|---|---|
| 银行 | 申万银行、中证银行、银行 ETF/联接 |
| 电力 | 申万公用事业中的电力、电力 ETF/联接 |
| 沪深300 | 指数及跟踪该指数的 ETF/联接 |
| 中证500 | 指数及跟踪该指数的 ETF/联接 |
| 煤炭 | 申万煤炭、煤炭 ETF/联接 |

大盘环境仍用上证、深成、创业板、科创50、两市成交额、涨跌家数、两融。不要为了交代风格再写一段银行/电力/300/500/煤炭点评。申万全表若必须引用，这五个只可出现在原始涨跌数字里，不展开、不加仓。

## 默认仍分析

通信、电子（含 CPO/PCB/光模块/通信设备）、计算机/软件、化工、医药、券商/非银、电力设备/电池、食品饮料/白酒、传媒、机械/机器人、科创50/半导体，以及用户当次点名的其他方向。

空仓方案不要再预留银行、电力、沪深300、中证500、煤炭的执行仓。现金比例按其余方向重算。

## 何时重新分析

用户写出上述名字，或说「看一下银行/电力/300/500/煤炭」时，仅对该次、仅对点名的方向恢复完整分析。
